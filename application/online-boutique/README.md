# online-boutique

This directory is a placeholder for the external "Online Boutique" microservices demo
application (https://github.com/GoogleCloudPlatform/microservices-demo), used as the
target workload for fault injection and remediation testing.

It is intended to be pulled in as a git submodule or cloned separately, e.g.:

```
git submodule add https://github.com/GoogleCloudPlatform/microservices-demo application/online-boutique
```
